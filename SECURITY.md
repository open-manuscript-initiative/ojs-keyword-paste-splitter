# Security policy

## Supported versions

Security fixes are provided for the latest published plugin release compatible with OJS 3.5.0 LTS.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's **Security → Report a vulnerability** function for this repository. Include the affected plugin and OJS versions, reproduction steps, impact, and any proposed mitigation.

Non-security defects should be reported through the public issue tracker.

## Data handling

This plugin processes pasted keyword text only in the authenticated editorial browser session. It creates no additional server-side storage and performs no external network requests.
